## The brief

A small task board for tracking work across To Do, In Progress and Done, quick enough to use without an account or a server.

## What I built

- **Three columns with drag and drop** to move tasks between stages.
- **Add and remove tasks**, each with a priority indicator.
- **A custom `useLocalStorage` hook** so the board's state persists across refreshes with no backend.

## What it shows

Component structure, state management and a reusable hook in React, kept small enough to read in one sitting. The code is public on GitHub.
